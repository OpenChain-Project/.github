# OpenChain Project

Welcome to the OpenChain Project GitHub organization. This GitHub organization contains materials related to all of the study and work groups, along with the general commmunity processes and policies.

## Work Groups

A Work Group is a specialized team within OpenChain that focuses on a specific area or task. Anyone can join a workgroup to learn, contribute and collaborate.

Below are the current Work Groups

- Specification
- Education
- [AI](https://github.com/OpenChain-Project/AI-WG)
- [SBOM](https://github.com/OpenChain-Project/SBOM-wg)
- Tooling	
- [Automotive](https://github.com/OpenChain-Project/Automotive-Open-Source-Governance-Monthly)
- [Telco](https://github.com/OpenChain-Project/Telco-WG)
